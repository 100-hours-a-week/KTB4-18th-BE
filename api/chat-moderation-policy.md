# 지역 텍스트 채팅 초기 탐지 기준

BE #141 / FE #134의 사용자 검토 결과를 기록한다. 예문 번호와 전화번호는 테스트용 가상 값이다.

## 검토 기록

- 2026-10-08: URL·개인정보 차단 제안에 사용자가 “제안한 URL·개인정보 차단 적용” 선택.
- 2026-10-08: 욕설·음란성 제재를 보류한 뒤 사용자가 “욕설·음란성 제재 그냥 적용해줘...”로 적용 승인. 아래 제안 목록과 예외 기준 적용.
- 초기 목록 변경·추가 시 차단/허용 예문을 다시 검토한다. 추정한 유사어를 자동 추가하지 않는다.

## 욕설·음란성: 메시지 차단 및 7일 제재

NFC 정규화 후 연속 문자열 포함 검사. 욕설은 `씨발`, `개새끼`, 음란성은 `자지 빨아`, `보지 빨아`이다.

| 예문 | 결과 |
| --- | --- |
| `씨발`, `너 개새끼`, `가사에 씨발이 있어` | PROFANITY, 저장/전달 전 차단 및 7일 제재 |
| `자지 빨아`, `보지 빨아` | OBSCENITY, 저장/전달 전 차단 및 7일 제재 |
| `시발점`, `성교육`, `병신`, `씨 발` | 초기 목록에 없는 표현. 이 탐지 기준으로 제재하지 않음 |

인용·가사 예외 없음. 띄어쓰기 우회와 유사어는 추정하지 않음. 제재 중 재탐지로 종료 시각을 연장하지 않음. 제재 종료 시각부터 입장 가능.

## URL·개인정보: 메시지만 차단

대소문자 구분 없이 포함 검사. 원문은 저장·전달·오류 로그에 남기지 않는다.

| 종류 | 검사 기준 / 차단 예문 |
| --- | --- |
| URL | `http://`, `https://`, `www.`, `.com`, `.net`, `.org`, `.kr`, `.io` 도메인. `https://example.com`, `sub.example.kr/a` |
| 주민등록번호 | 날짜 모양 6자리 + 성별 1~4 + 6자리. `000101-1000000`, `0001011000000` |
| 여권번호 | M/S/R/D/O + 숫자 8자리 또는 해당 접두 문자 + 숫자 3자리 + 영문 1자리 + 숫자 4자리. `M00000000`, `M000A0000` |
| 휴대전화 | 010/011/016/017/018/019 + 3~4자리 + 4자리. `010-0000-0000` |
| 일반전화 | 02, 03~06 계열 지역번호, 070 + 3~4자리 + 4자리. `02-0000-0000`, `031 000 0000` |
| 국제 표기 | 국내 접두 0을 `+82`로 대체. `+82-10-0000-0000` |

숫자 묶음 사이 하이픈·공백 1개 또는 구분자 없음 허용. 실제 발급 여부·체크섬은 확인하지 않는다. 전화번호와 구별할 수 없는 숫자열도 차단될 수 있다.

허용 예문: `2026-10-08`, `BPM 120`, `곡 번호 12345`, `시발점`, `성교육`. URL 전체 TLD·난독화·이메일·주소 등 미검토 유형을 자동 확장하지 않는다.

## 운영 설정

`CHAT_MESSAGE_MINIMUM_INTERVAL` 기본 `1s`, `CHAT_PERSONAL_CONTENT_DETECTION_ENABLED` 기본 `true`, `CHAT_AUTOMATIC_BAN_ENABLED` 기본 `true`. 목록은 `chat.message-policy.profanity/obscenity` 설정. 변경 시 서버 재시작 필요.
