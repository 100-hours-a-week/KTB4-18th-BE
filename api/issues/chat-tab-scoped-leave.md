# [BE][TASK] 탭별 채팅방 퇴장

## 목적

같은 인증 세션의 여러 탭이 참여 ID를 공유하더라도 화면을 떠난 탭만 종료한다.

## 사용자 시나리오

- 두 탭 중 한 탭에서 다른 메뉴로 이동하면 해당 탭만 즉시 퇴장하고 다른 탭과 기기는 계속 대화한다.
- 연결 전이나 입장 응답 대기 중 화면을 떠나도 해당 입장만 정리한다.
- 일시적인 통신 단절은 기존 30초 복구를 유지하고 명시적으로 퇴장한 열람 세션은 재사용하지 못한다.

## 범위

- 포함: 입장 시 탭 식별자 발급·전달, 탭 단위 종료와 예약·연결·열람 권한 정리, 기존 지역 이동 범위 유지, 회귀 검증과 계약 문서.
- 제외: 로그아웃 정책 변경(B7), 계정 이력 통합(B8/B9), 공동 재생, 전체 모바일 검증(F4).

## 완료 조건

- [x] 같은 sid의 남은 탭과 다른 sid 기기의 연결·정원을 유지한다.
- [x] 연결 전·입장 지연·중복 퇴장과 종료 식별자 재연결을 검증한다.
- [x] 위치로 확인한 지역 이동은 같은 sid 전체 종료를 유지한다.
- [x] 관련 정적 검사·통합 테스트와 API 문서 갱신 결과를 기록한다.
