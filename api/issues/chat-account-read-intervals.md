## 상위 [BE][FEATURE] 이슈

- 결과: 같은 계정의 여러 탭·기기·종료된 참여에서 허용된 구간의 합집합을 방별로 산출한다.

## 작업 범위

- 포함: 현재 활성 구독의 권한 검증, 계정·방 단위 기존 구간 조회, 종료된 참여·재로그인 구간 포함, 활성 다른 탭 checkpoint 반영, 24시간 보관·30초 단절 경계 유지, 합집합 권한 판정과 통합 검증.
- 제외: B9 메시지 조회 API·cursor·gap 변경, FE 이력 복원, 인증 정책·로그아웃 API, 공동 재생.

## API / 도메인 / 데이터 영향

- 신규 내부 산출 진입점만 제공한다. 기존 탭별 조회·복구 API는 바꾸지 않는다.
- 계정·방 소유권과 현재 membership/view/실제 구독·제재 상태를 검증한다.
- 종료된 과거 view는 이력의 근거이며 재연결 권한으로 재사용하지 않는다.
- 모든 기기의 부재 구간, 다른 사용자·방 기록은 포함하지 않는다.
- 기존 테이블을 사용한다. DDL·Flyway·환경 변수 변경은 없다.
