# [BE][TASK] 변경된 참여 모델의 재시작 복구 검증

## 상위 [BE][FEATURE] 이슈

기존 지역 채팅 다중 탭·기기 정책 개선 부모에 연결한다. 실제 이슈 번호·담당자·예상 소요·PR은 등록 시 연결한다.

## 작업 범위

- 동일 실제 JVM/MySQL에서 한 계정의 여러 sid·같은 sid 여러 탭·다른 지역 참여 구성
- 실제 child JVM 강제 종료·동일 DB 재시작과 PID 변경 확인
- sid/탭별 checkpoint 경계, 종료된 view/참여 재사용 거절 검증
- 재시작 이후 계정·방 history와 현재 탭 recovery 및 계정 정원 분리 검증
- 재로그인 이력·현재 sid 소유권·삭제된 구간·만료 기록의 안전한 제외 확인
- 제품 인증·로그아웃 정책·FE·DB migration·공동 재생 변경은 제외

## API / 도메인 / 데이터 영향

기존 REST/STOMP와 운영 코드를 사용하는 통합 검증이다. 외부 역지오코딩은 합성 fixture다.
실제 로그인 쿠키·인증 세션 폐기·물리 GPS·모바일 E2E는 범위에 포함하지 않는다.
DDL·공개 API 계약·환경 변수 변경 없이 기존 chatProcessTest를 확장한다.
