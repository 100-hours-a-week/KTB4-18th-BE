# [BE][TASK] 계정 참여 이력 기반 메시지 조회

## 상위 기능 이슈

기존 지역 채팅 다중 탭·기기 정책 개선 부모 이슈에 연결한다. 실제 번호·담당자·예상 시간·PR은 등록 시 연결한다.

## 목적과 작업 범위

같은 계정의 다른 탭·기기·재로그인에서도 최근24시간의 허용된 참여 대화를 복원한다.
BE는 B8 계정·방 구간을 history 조회에 적용하고 현재 참여/구독 권한과 고정 snapshot cursor를 검증한다.
FE는 구독 준비 후 서버 history와 탭 복구·실시간 메시지를 병합하고 최신200개를 표시한다.
각 저장소는 해당 영역의 API 또는 화면/상태/연동과 테스트·문서를 담당한다.
인증 정책·토큰 폐기·탭 로그아웃 전파, 새로운 DB 구조·공동 재생·운영 배포는 제외한다.

## 계약 및 영향

- history는 계정·방 참여 합집합, recovery는 기존 현재view 범위를 유지한다.
- 모든 기기가 부재한 메시지와 다른 계정·방은 제공하지 않는다.
- 현재 JWT sid 소유 참여/실제 구독·제재·퇴장을 검증하고 cursor는 현재문맥에 결합한다.
- FE 캐시는 임시 표시이며 서버 복원 성공 시 서버 결과로 대체한다. 실패 시 전송을 막고 수동 재시도를 제공한다.
- DB migration·환경 변수 변경 없음. 변경 계약과 배포/롤백 조건을 문서화한다.

## 완료 조건

- [x] 여러 탭/sid·재로그인의 과거 허용 메시지를 복원한다.
- [x] snapshot 고정·페이지 중복 제거·live 병합과 부재 제외를 검증한다.
- [x] 계정/세션 전환·퇴장·제재·권한 오류·취소 시 늦은 결과를 반영하지 않는다.
- [x] 최신200개·24시간 제한과 기존 탭 복구를 유지한다.
- [x] 관련 단위·실제 서버 연동 검사와 문서 갱신을 완료한다.

## 의존성 및 검증 계획

B8 산출을 사용한다. B7의 인증 담당자 이벤트 발행 의존성은 그대로 유지한다.
BE는 MySQL/HTTP/서명 cursor와 구간 경계를, FE는 페이지 복원·캐시 대체·취소·실시간 병합을 검증한다.
