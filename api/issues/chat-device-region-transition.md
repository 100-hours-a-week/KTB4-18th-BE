# [BE][TASK] 지역 이동 영향 범위 분리

## 목적과 범위

- B4 참여 분리를 바탕으로 이동한 인증 세션의 참여·연결만 종료한다.
- 위치 판정 결과를 서명된 sid에 결합하고 다른 sid·기존 무세션 토큰으로 채팅 입장을 시도하면 기존 참여 변경 전에 거절한다.
- 같은 세션의 기존 방 종료와 목적지 정원 검증 순서, 다른 세션의 참여 유지, 예약·연결 정리를 검증한다.
- 음악 기록의 기존 위치 토큰 사용과 일반 위치 판정 계약은 유지한다.
- 탭별 퇴장·로그아웃·이력 통합·GPS 위조 방지는 이번 범위가 아니다.

## 계약과 의존성

- B4 PR #200이 현재 브랜치에 병합되어 있다. FE F2와 함께 연동한다.
- 공개 JSON 필드는 유지한다. 채팅 입장은 새로 판정한 현재 sid의 위치 토큰을 요구한다.
- DB 스키마·Flyway 변경은 없다. 실제 GitHub 이슈 번호는 확인 후 연결한다.

## 완료 조건

- [x] 다른 sid·무세션·만료·지역 불일치 토큰이 다른 참여를 변경하지 않는다.
- [x] 이동 성공·목적지 만석에서도 다른 세션의 연결·참여를 유지한다.
- [x] 기존 위치·음악 기록과 실제 HTTP/WebSocket 회귀를 검증한다.

## 결과

- 원본 정적 검사와 격리 사본 관련 263개 통과/기존 조건부 6개 제외, 실제 FE 연동 및 최종 입장 25개 재검증 통과.
- 원본 빌드 차단과 적용 조건은 `../chat-device-region-transition.md`에 기록했다.
